# متاجر برو — نظام SaaS متعدد المتاجر مع دعم العمل دون إنترنت (PWA)

إصدار PWA: يعمل على iPhone وAndroid والكمبيوتر، قابل للتثبيت، يحفظ المبيعات محلياً على الجهاز ويزامنها تلقائياً عند عودة الاتصال.

## الجديد في هذا الإصدار
- **PWA قابل للتثبيت**: `manifest.json` + `sw.js` (Service Worker) يخزّن غلاف التطبيق للعمل دون اتصال.
- **IndexedDB** (`static/localdb.js`): يخزن المنتجات والفواتير وحركات المخزون محلياً، بفصل نطاق `tenantId:storeId` (لا يصل مستخدم آخر لبيانات متجر سابق على نفس الجهاز).
- **بيع موثوق محلياً**: الفاتورة تُحفظ في IndexedDB أولاً، ولا يُظهر النجاح إلا بعد التأكيد.
- **طابور مزامنة دائم**: كل فاتورة بمعرف UUID فريد (`client_uid`) يمنع التكرار مطلقاً حتى مع إعادة الإرسال. إعادة محاولة تلقائية كل 15 ثانية وعند عودة الاتصال.
- **شاشة مزامنة**: عدد العمليات غير المتزامنة، آخر مزامنة، قائمة الأخطاء، إعادة مزامنة يدوية، تصدير نسخة احتياطية JSON.
- **سياسة الاشتراك**: إذا انتهى الاشتراك أثناء العمل دون إنترنت، تستمر حفظ المبيعات محلياً وتتوقف المزامنة حتى التجديد — **لا تُحذف البيانات أبداً**.
- **دعم PostgreSQL**: عبر متغير `DATABASE_URL` (وإلا SQLite للتطوير). انظر `db.py` و`SCHEMA_POSTGRES`.
- **الطباعة/الباركود**: لا يُفترض عملهما على كل جهاز — قارئ الباركود مدعوم إن عمل كلوحة مفاتيح، والطباعة عبر `window.print()` مع تنسيق إيصال. اختبر التوافق على جهازك.

## التشغيل
```bash
pip3 install -r requirements.txt
python3 app.py   # http://localhost:5000
```
حسابات تجريبية (كلمة المرور: `demo1234`): `owner@alnour.com` (فرعان)، `cashier@alnour.com`، `owner@baraka.com`.

## النشر على الإنترنت
1. ارفع المشروع لـ GitHub وانشر على **Railway/Render**، أضف `SECRET_KEY` و`DATABASE_URL` (PostgreSQL).
2. أو على VPS: `gunicorn --bind 0.0.0.0:8000 app:app` خلف Nginx مع شهادة Let's Encrypt.
3. HTTPS إجباري (Service Worker لا يعمل بدون HTTPS إلا على localhost).
4. اربط نطاقك الخاص. العملاء يفتحون الرابط من أي متصفح ويثبّتون التطبيق على أجهزتهم.

## قبل النشر التجريبي
- غيّر `SECRET_KEY`، احذف الحسابات التجريبية، استخدم PostgreSQL مع نسخ احتياطي يومي.
- راجع `TEST_REPORT.md` لمعرفة الاختبارات المنفذة فعلياً والتي تحتاج اختباراً على أجهزة حقيقية.
- خطر: إذا فُقد الجهاز قبل مزامنة العمليات المعلقة، لا يمكن استرجاعها — شجّع النسخ الاحتياطي الدوري من شاشة المزامنة.

## هيكل الملفات
```

db.py               قاعدة بيانات موحدة SQLite/PostgreSQL + التعبئة
requirements.txt    التبعيات (يشمل psycopg2-binary)
Dockerfile
TEST_REPORT.md      تقرير اختبارات صادق
templates/index.html
static/
  app.js            منطق الواجهة (Offline-First + محرك المزامنة)
  localdb.js        طبقة IndexedDB
  sw.js             Service Worker
  manifest.json     بيان PWA
  icon-192.png, icon-512.png
  style.css
```
